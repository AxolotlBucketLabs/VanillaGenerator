# Repository guidance

Use the [AxolotlBucketLabs skill](https://github.com/AxolotlBucketLabs/axolotl-bucket-labs/blob/main/SKILL.md) for this Axolotl-PM plugin. Read its [writing style](https://github.com/AxolotlBucketLabs/axolotl-bucket-labs/blob/main/references/writing-style.md) before writing human-facing prose.

Follow the skill's technical guidance for Axolotl-PM and PocketMine-MP. Do not apply AxolotlBucketLabs organization policy unless this repository is moved under that organization.

Write natural, complete sentences. Do not use em dash or en dash punctuation or semicolons in prose. Avoid unnecessary label-shaped sentences. Use Markdown inline code for technical names and paths.
